Practical 10: RESTful web service for creating a books collection using an entity class
AIM: Write a RESTful web service for creating books collection using entity class.


==================== PART A: DATABASE ====================

Step 0: Create the database in MySQL (the doc uses the database tycs43):

CREATE DATABASE tycs43;
USE tycs43;
SHOW TABLES;

After the application is deployed and run, the tables books and sequence are created
automatically:
  mysql> show tables;
  +-----------------+
  | Tables_in_tycs43|
  +-----------------+
  | books           |
  | sequence        |
  +-----------------+
  2 rows in set

==================== PART B: NETBEANS STEPS ====================

Step 1: Create a new web project (File > New Project > Java Web > Web Application).

Step 2: Create a new entity class.
        Right-click the project > New > Entity Class.
        Class Name: books, Package: ty, Primary Key Type: Long > Finish.
        Write the code below.

---------- books.java (package ty) ----------
/*
* To change this template, choose Tools | Templates
* and open the template in the editor.
*/

package ty;

import java.io.Serializable;
import javax.persistence.Entity;
import javax.persistence.GeneratedValue;
import javax.persistence.GenerationType;
import javax.persistence.Id;
import javax.xml.bind.annotation.XmlRootElement;

/**
*
* @author Administrator
*/
@Entity
@XmlRootElement
public class books implements Serializable {

    private static final long serialVersionUID = 1L;

    @Id
    @GeneratedValue(strategy = GenerationType.AUTO)
    private Long id;

    private String bname;

    private String tbook;

    private int price;

    /**
    * Get the value of price
    *
    * @return the value of price
    */
    public int getPrice() {
        return price;
    }

    /**
    * Set the value of price
    *
    * @param price new value of price
    */
    public void setPrice(int price) {
        this.price = price;
    }

    /**
    * Get the value of tbook
    *
    * @return the value of tbook
    */
    public String getTbook() {
        return tbook;
    }

    /**
    * Set the value of tbook
    *
    * @param tbook new value of tbook
    */
    public void setTbook(String tbook) {
        this.tbook = tbook;
    }

    /**
    * Get the value of bname
    *
    * @return the value of bname
    */
    public String getBname() {
        return bname;
    }

    /**
    * Set the value of bname
    *
    * @param bname new value of bname
    */
    public void setBname(String bname) {
        this.bname = bname;
    }

    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    @Override
    public int hashCode() {
        int hash = 0;
        hash += (id != null ? id.hashCode() : 0);
        return hash;
    }

    @Override
    public boolean equals(Object object) {
        // TODO: Warning - this method won't work in the case the id fields are not set
        if (!(object instanceof books)) {
            return false;
        }
        books other = (books) object;
        if ((this.id == null && other.id != null) || (this.id != null && !this.id.equals(other.id))) {
            return false;
        }
        return true;
    }

    @Override
    public String toString() {
        return "ty.books[ id=" + id + " ]";
    }

}

Step 3: Create new RESTful web services from the entity class.
        Right-click the project > New > RESTful Web Services from Entity Classes.
        Select the entity class ty.books > Add > Next > Finish.

Step 4: Create new JSF pages from the entity class.
        Right-click the project > New > JSF Pages from Entity Classes.
        Select ty.books > Next > Finish.

Step 5: Connect the MySQL connector to NetBeans.
        Services > Databases > Drivers > MySQL (Connector/J driver) > Connect Using.
        Host: localhost, Port: 3306, Database: tycs43, User: root, Password: your MySQL password.
        Click Test Connection (message: Connection succeeded) > Next > Finish.
        JDBC URL: jdbc:mysql://localhost:3306/tycs43

Step 6: Deploy and run the project. Add books (bname, tbook, price) with the JSF pages.

OUTPUT: The JSF pages list the books collection, and the REST resource returns the books
        (right-click the RESTful Web Services node > Test RESTful Web Services).
