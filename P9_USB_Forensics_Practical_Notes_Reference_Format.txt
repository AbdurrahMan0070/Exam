Practical no: 09

Aim: To find last connected USB on your system (USB Forensics)

======================== STEPS TO PERFORM ========================

Step 1: Download USBDeview.
        - Open a browser.
        - Go to:
          https://www.nirsoft.net/utils_devices_view.html
        - Download USBDeview.

Step 2: Open the downloaded ZIP file.
        - Double click the ZIP file.
        - Locate USBDeview.exe.

Step 3: Run USBDeview.exe.
        - Open the application.
        - USBDeview displays USB devices currently and previously
          connected to the computer.

Step 4: View the USB device history.
        - Check the list of USB devices displayed by USBDeview.
        - Use the connection/time information shown in the list to
          identify the most recently connected USB device.

Step 5: View detailed information about a USB device.
        - Select the required USB device.
        - Open its Properties/details.
        - Observe information such as Device Name, Device Type,
          Connected, Disabled, Drive Letter, Serial Number,
          Registry Time, VendorID, ProductID, USB Class, USB Subclass,
          Computer Name, Service Name and Driver Version.

Step 6: Identify the last connected USB.
        - Compare the available time/history information of the USB
          devices.
        - Select the device with the most recent connection information.
        - Record its device details.

Step 7: Take screenshots of the USBDeview device list and the detailed
        USB device properties.


======================== NOTES (THEORY) ======================

USB Forensics
- USB forensics is the process of examining USB device information
  and connection history on a computer.
- It can help identify USB devices currently or previously connected.

USBDeview
- USBDeview is a free and lightweight Windows utility by NirSoft.
- It lists USB devices currently and previously connected to a computer.
- It displays detailed information about USB devices.

USB Device History
- USBDeview provides information about USB devices connected to the
  computer.
- The history can be examined to identify recently connected devices.

Device Name
- Shows the name or identifier of the USB device.

Device Type
- Shows the type/category of the USB device.

Connected
- Shows whether the device is currently connected.

Serial Number
- Shows the serial number of the USB device when available.

VendorID
- Identifies the vendor/manufacturer of the USB device.

ProductID
- Identifies the particular USB product/device.

Registry Time
- Shows recorded registry-related time information for the device.

Properties
- The Properties/details window provides additional information about
  the selected USB device.

Memory trick:
USBDeview = USB history
Connected = current status
Serial Number = device identification
VendorID = manufacturer
ProductID = product
Properties = detailed information
