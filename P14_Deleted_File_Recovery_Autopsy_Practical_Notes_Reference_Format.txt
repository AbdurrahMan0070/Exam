Practical no: 14

Aim: Recovering and Inspecting deleted files.

- Check for Deleted Files
- Recover the Deleted Files
- Analyzing and Inspecting the recovered files
- Perform this using recovery option in ENCASE and also perform manually
  through command line

NOTE:
- The screenshots in the provided practical use Autopsy 4.21.1 for the
  recovery and analysis workflow. No separate EnCase or command-line
  recovery commands are shown in the provided screenshots, so no command
  has been invented here.

======================== NOTES (THEORY) ======================

Deleted File Recovery
- Deleted file recovery is the process of finding and recovering files
  that have been deleted from a storage device.

Autopsy
- Autopsy is a digital forensics platform used to analyze digital
  evidence.
- It can add data sources, run ingest modules, search evidence, recover
  files and generate reports.

Case
- A case is a workspace where forensic evidence and analysis results
  are organized.
- The practical shows the case name as Alexa.

Data Source
- A data source is the disk, image or other evidence added to Autopsy
  for examination.
- The practical uses a Local Disk.

Local Disk
- A local disk is a physical storage device connected to the system.
- The practical screenshot shows a selected E: drive.

Ingest Modules
- Ingest modules process the added evidence and extract useful
  forensic information.
- Examples shown include Recent Activity, Hash Lookup, File Type
  Identification, Picture Analyzer and PhotoRec Carver.

PhotoRec Carver
- It is an ingest module shown in the practical for file recovery/
  carving from the data source.

File Extraction
- File extraction saves a selected item from the analyzed evidence to
  another location for examination.

Generate Report
- Autopsy can generate reports containing the results of the forensic
  analysis.
- The practical shows HTML, Excel and text-related report options.

Excel Report
- The practical generates an Excel report.
- The final screenshot shows case summary information including:
  Case Name: Alexa
  Case Number: 1
  Number of data sources in case: 1
  Case Notes: Hello
  Examiner: khani

Ingest Warning
- The practical shows warnings for Keyword Search and Cyber Triage.
- The warning states that the Keyword Search index could not be opened
  or does not exist and that no Cyber Triage license code was loaded.

Memory trick:
Case = create workspace
Data Source = add evidence
Ingest = analyze evidence
Extract = recover/save file
Report = final forensic result
