======================== NOTES (THEORY) ======================

Forensic Image
- A forensic image is a copy of digital evidence created for forensic
  examination.
- It allows investigators to examine evidence without working directly
  on the original source.

FTK Imager
- FTK Imager is a forensic imaging and evidence examination tool.
- It can create forensic images, verify image integrity and analyze
  evidence.

Source Evidence
- Source evidence is the drive, image, folder or other evidence selected
  for creating the forensic image.

Image Destination
- Image destination is the location where the created forensic image
  is saved.

MD5 Hash
- MD5 is a hash value used to check the integrity of data.
- FTK Imager compares the calculated and reported hash values.

SHA1 Hash
- SHA1 is another hash value used for integrity verification.

Verify Result: Match
- Match means the calculated hash and reported hash are the same.
- This indicates that the image passed the verification shown in the
  practical.

Evidence Tree
- Evidence Tree displays the added forensic evidence and its structure.
- It is used to browse the contents of the forensic image.

Image File
- An image file is a forensic image added to FTK Imager for analysis.
- The practical uses the created image file image2.ad1.

Compression
- Compression reduces the storage space required for the forensic image.
- The screenshot shows compression level 5.

Image Fragment Size
- It specifies the size of image fragments when the image is divided
  into parts.
- The practical screenshot shows 1500 MB.

Memory trick:
Create Image = Source -> Destination -> Start
Integrity = MD5 + SHA1
Match = Verified
Analyze = Add Evidence -> Image File -> Evidence Tree
