Practical 11: REST API that returns player data in both XML and JSON
AIM: Create REST API that returns data in both XML and JSON format of player database.


==================== STEPS ====================

Step 1: Create the database in MySQL

mysql> create database ty;
Query OK, 1 row affected (0.00 sec)

mysql> use ty;
Database changed
mysql> show tables;
Empty set (0.00 sec)

Step 2: Create a Java Web Application (project name: Player Jsonxml).

Step 3: Create an Entity Class.
        Right-click the project > New > Entity Class.
        Class Name: Player1, Package: ty, Primary Key Type: Long > Finish.

Step 4: Check the web application by deploying and running it.

Step 5: Create the RESTful web service from the entity class.
        Right-click the project > New > RESTful Web Services from Entity Classes.
        Select tycs.Player (Available Entity Classes) > Add > Next > Finish.

Step 6: Go to the RESTful Web Services folder in Player Jsonxml.

Step 7: Click PlayerFacadeREST [tycs.player] and go to the findAll() method.

Step 8: Remove "application/xml" from the findAll() method and the reverse for
        "application/json" (make findAll() produce only one of the two formats).

Step 9: Describe player in the ty database
mysql> show tables;
+--------------+
| Tables_in_ty |
+--------------+
| player       |
| sequence     |
+--------------+
2 rows in set (0.00 sec)

mysql> use player;
ERROR 1049 (42000): Unknown database 'player'
mysql> desc player;
+-------+------------+------+-----+---------+-------+
| Field | Type       | Null | Key | Default | Extra |
+-------+------------+------+-----+---------+-------+
| ID    | bigint(20) | NO   | PRI | NULL    |       |
+-------+------------+------+-----+---------+-------+

Step 10: Insert the details of the player
mysql> insert into player values(1);
Query OK, 1 row affected (0.00 sec)

mysql> insert into player values(2);
Query OK, 1 row affected (0.00 sec)

Step 11: Check the web application by deploying and running it.

Step 12: In RESTful Web Services > PlayerFacadeREST [tycs.player], use "Test Resource Uri".

Step 13: For JSON output use this method in PlayerFacadeREST:

@GET
@Override
@Produces({"application/json"})
public List<Player> findAll() {
    return super.findAll();
}

Output shown in the doc (JSON):
[{"id":1},{"id":2}]

Step 14: For XML output use this method in PlayerFacadeREST:

@GET
@Override
@Produces({"application/xml"})
public List<Player> findAll() {
    return super.findAll();
}

Output shown in the doc (XML):
<players>
  <player>
    <id>1</id>
  </player>
  <player>
    <id>2</id>
  </player>
</players>

Other steps (entity class Player1 in package ty, RESTful Web Services from
Entity Classes with tycs.Player, test resource URI) are NetBeans wizards with
no hand-written code in the doc.

NOTE: Entity class, RESTful web service steps are NetBeans wizards. The only hand-written code is
the findAll() method with @Produces({"application/json"}) or @Produces({"application/xml"}).
