Practical no: 15

Aim: To study the steps for hiding and extract any text file behind an
image file/audio file using command prompt.

======================== STEPS TO PERFORM ========================

Step 1: Create a new folder in C drive.
        - Create:
          C:\Stegano

Step 2: Download/select the required files.
        - Place one image file such as:
          images.jpg
        - Place one text file such as:
          message.txt
        - Save both files inside:
          C:\Stegano

Step 3: Open Command Prompt.

Step 4: Change the directory to the Stegano folder.

        Type:
            cd C:\Stegano

Step 5: Combine the image file and text file into a new image file.

        Type:
            copy /b images.jpg+message.txt hidden.jpg

        OUTPUT:
        The command copies the image and text file together and creates:
            hidden.jpg

Step 6: Check the hidden file.

        Type:
            type hidden.jpg

        OUTPUT:
        The command displays the contents of the file in Command Prompt.
        The practical screenshot shows the beginning of the JPEG data.

Step 7: Check the file sizes in the Stegano folder.

        Type:
            dir

        OUTPUT:
        The screenshot shows:
            hidden.jpg   70,270 bytes
            images.jpg   70,244 bytes
            message.txt  26 bytes

        Observation:
        The size of hidden.jpg is the combined size of the original
        image and text data.

Step 8: Take screenshots of:
        - C:\Stegano folder containing the image and text file.
        - cd C:\Stegano command.
        - copy /b command and its output.
        - type hidden.jpg output.
        - dir output showing the file sizes.


NOTE:
- The provided document demonstrates the hiding/combining process and
  checking the resulting file size.
- Although the aim mentions extracting the hidden text file, no separate
  extraction command is shown in the provided practical document.
- Therefore, no extraction command has been invented here.


======================== NOTES (THEORY) ======================

Steganography
- Steganography is the technique of hiding information inside another
  file or medium.
- In this practical, a text file is combined with an image file.

Cover File
- The original file used to carry the hidden information.
- Here, the image file is the cover file.

Hidden File
- The file containing the information that is hidden.
- Here, message.txt is the text file being hidden.

Hidden Image
- The new image file created after combining the image and text file.
- Here, the output file is:
  hidden.jpg

copy /b
- /b means binary copy.
- It allows the image and text file data to be copied together.

type
- The type command displays the contents of a file in Command Prompt.

dir
- The dir command displays the files and folders in the current directory.
- It also shows file sizes.

File Size
- Original image:
  70,244 bytes
- Text file:
  26 bytes
- Hidden image:
  70,270 bytes

Memory trick:
Steganography = Hide information
Cover file = Image
Hidden file = Text
copy /b = Combine
type = Display
dir = Check files and size
